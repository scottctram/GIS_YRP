Welcome to the City of Waterloo Environmental Infrastructure Web Map!

This interactive map application features:

  • Layers: Points, Trees, Water, Sewers, and Parks.
  • Buffer Tool: Click any feature popup to buffer it and find nearby items.
  • Search & Query: Find locations and filter attributes.
